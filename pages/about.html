About me


Hi I am {{ site.author.name }} :wave:,

I'm a Senior Software Engineer with a backend-heavy toolkit — Python, JavaScript, TypeScript, Node.js, C/C++ — and a soft spot for systems that scale across finance, e-commerce, and multimedia 🛠️💻. Half my coworkers are LLMs now 🤖👔, and I like it that way.

Right now I'm remote at Simplified, TLDR Technologies Inc., where I design and ship LLM-powered video agents 🎬🤖 — fully agentic, end-to-end pipelines for AI-driven video generation, repurposing, and subtitling. I build agent orchestration with LangGraph, user-facing AI copilots with CopilotKit, and spend a suspicious amount of time on prompt engineering & evaluation so the agents actually behave in production. On the engineering side, I automate the full coding pipeline — code gen, PR review, test authoring, CI/CD — with agentic coding workflows using Claude Code and Cursor ⚡. And yes, there's still plenty of FFmpeg, multi-cloud (AWS / GCP / Azure), and database work underneath it all.

Before Simplified I led backend and e-commerce work at Aubergine Solutions 🚀, and started my career at Nividata building fintech and blockchain systems 🔐💰. Back when I was a programming newbie 🧑‍💻, I dabbled in IoT projects 🌐 and low-level C/C++.

I'm a regular on StackOverflow and GitHub, with a shelf of awards and badges 🏅. My tech journey is powered by an IT degree, Scrum Master certifications, and an unquenchable thirst for learning — plus strong coffee ☕.
